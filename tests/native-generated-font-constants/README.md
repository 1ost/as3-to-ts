# Generated FontPosture and FontWeight bindings

The existing production factory emits the complete unchanged FontUse AS3
subject with explicit common engine canonical providers. No compiler lowering
change or application-local constant substitute is needed. The five source
calls and 38 common engine Class observations agree with AIR on ES5/ES2015 in
Node and CSP Chromium, with zero strict type diagnostics.

Two missing-provider guards keep unresolved native Class names held. An applied
wrong-constant control executes the generated factory and fails its original
source observations. The engine's twelve identity/state guards also run in each
factory realm. Reflection XML comparison removes only inter-element whitespace;
raw strings are retained and XML pretty-print serialization remains unqualified.

Run `npm run tsc`, then
`node tests/native-generated-font-constants/run.cjs`.
Set LAYA_ENGINE_REPOSITORY if the common engine checkout differs from
`../LayaAir-op2-font-constants-review`.
`node tests/native-generated-font-constants/verify.cjs --check-current`
authenticates the retained result and exact inputs. Text layout, all remaining
PagraphData/ParagraphElement dependencies, and game startup are separate work.
