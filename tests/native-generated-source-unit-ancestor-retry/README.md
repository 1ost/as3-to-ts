# Retryable source ancestors with a private-helper source unit

TextFlow's root ancestor FlowElement is itself a retryable Class script. This
fixture extends the ordinary-ancestor qualification with root and intermediate
ancestor failures before descendant publication. An ordinary Bridge between a
retrying ancestor and a retrying descendant mirrors the mixed ancestry in TLF.

The 74 repeated AIR rows cover failed parent Class/global/array/function/instance
identities, parent initialization preceding owner/helper initialization, successful
parents surviving later owner/helper failures, early/deferred private-helper
selection, inherited state, constructor arguments and interface membership.
Both ES5/ES2015 match Node and strict-CSP Chromium with zero type errors, nine
rejection guards and 15 domain checks. Five mutations per target are detected:
early helper selection, failed global retention, constructor arguments, ancestor
retry authority and Function intrinsic lowering. The prior planner is executed
against this exact source cohort and its rejection is retained.

Run with LAYA_ENGINE_REPOSITORY and PLAYWRIGHT_MODULE set:

```
npm run tsc
node tests/native-generated-source-unit-ancestor-retry/run.cjs
node tests/native-generated-source-unit-ancestor-retry/verify.cjs --check-current
```

The updated ordinary-ancestor regression also passes its 62 rows, nine rejection
guards, two positive ancestor-selection checks, 15 domain checks and four mutations
per target. Its old runtime archive is preserved as historical evidence; this
fixture's archive retains the current adjacent run and exact inputs.

Native ancestry, inherited helpers, ancestors with private declarations, multiple
helpers and private interfaces remain outside this new allowance. Whole OP2
factory/type/runtime and real H5 acceptance are not implied by these tests.
