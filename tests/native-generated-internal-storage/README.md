# Generated package-internal storage

Run `node tests/native-generated-internal-storage/run.cjs --combined` (and without
`--combined`). Five complete unchanged subjects from the common engine AIR packet
match all 19 observations on generated ES5/ES2015 in Node/Chromium. The runner checks
source/artifact hashes through the engine verifier, zero generated/dependency type
errors, 15 compiler rejection guards and three comparison negative controls.

An explicit `lexicalProviderModule` on the authenticated declaration plan publishes
sealed package membership over exact class tokens. Typed foreign accesses use
those declaration identities without resolving a Class just to find storage.
Dynamic package accesses retain the caller's lexical scope. Internal uint literal
field values are installed across the inherited chain before authored effects;
classes in different packages retain distinct same-named fields.

The new admission is instance uint variables with absent or in-range integer
literal initializers, and static uint constants with in-range integer literals.
Other types, methods/accessors, computed initializers, inherited static lookup,
compound updates and constant assignments remain held. This fixture does not
qualify Zip/ZipFile, cross-loaded package sharing, or the whole application.
