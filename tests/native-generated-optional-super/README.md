# Generated optional super calls

Run `npm run tsc`, then `node tests/native-generated-optional-super/run.cjs`.
Complete maintained test sources are authenticated by the engine's
`optional-super` AIR packet and built through production parent/child factories.
Direct-super lowering validates the parent's qualified literal defaults and
minimum/maximum arity, then passes exactly the authored argument list. Existing
parent entry code distinguishes omitted arguments from explicit undefined.

`run-m8vtMs`: thirteen AIR rows on ES5/ES2015 in Node and Chromium CSP, zero
types, three domain/lifetime checks, fourteen compiler rejection cases, and two
applied mutations. Padding omitted range arguments with undefined must change
the observed values; bypassing selected-parent reuse must fail publication.
The six direct-super rejection cases cover missing/extra arguments, rest,
out-of-range integer defaults, expression defaults and required-after-optional.

Reference overrides still pass ten AIR rows (`run-yuMhFp`), and both lexical
Function configurations pass 38 rows (`run-6J4kGl`, `run-bh6UZy`). Optional
override contracts, rest super calls, native parent methods and full OP2 startup
remain separate qualifications.
