# Generated Object-field method calls

Run `node tests/native-generated-object-field-calls/run.cjs`. The complete
Subject comes from the shared engine's authenticated twelve-row AIR packet.
Its private static/instance Object fields retain lexical identity while dot
method calls use common AS3 namespace lookup and evaluate arguments before
final lookup. Explicit `this`, local shadowing, null errors, receiver identity
and isolated domains are covered on ES5/ES2015 in Node/Chromium under CSP.

`--calls-only` compares nine call/order/ordinary-write rows, retaining all actual
rows in the report. Three AS3 method-name write rows separately expose a shared
lexical property bridge defect. A call-order mutation must change the AIR result;
generated/provider type errors must be zero. This mode does not qualify those
three writes. The default full comparison remains required for integration.

The native observer supplies registered ordinary Objects for source object
literals that will be written. The original static `call` probe spelling remains
held as a reserved Class member; the captured `invoke` spelling has identical
observations. Full ResourceLoader and game startup remain separate work.
