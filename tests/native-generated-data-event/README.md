# Generated DataEvent construction and references

Complete original model.DataEventUse from the pinned AIR fixture now emits as
one native source module. Its eight maintained fixture methods cover constructor
defaults and supplied arguments, data reads, constants, item-index selection,
casts and is/as checks. No method body is reconstructed by the observer.

Native helpers were qualified separately in LayaAir-op2-data-event-review at
4c0ee73cd. The compiler uses the combined display-accessor/DataEvent engine at
0d177fba3c05c932b87a8b0c5e553c63ee6f1020. The frozen source and original AIR
receipt still come from 4c0ee73cd; the combined engine has a fresh native proof.

Generated ES5 and ES2015 match all 36 AIR observations in Node and CSP Chromium,
including reverse argument coercion, conversion failures, nullable payloads,
nominal type checks, data/text aliasing, clones and actual EventDispatcher dispatch.
The oracle's ChildData is a native host observation fixture, not a generated
subclass qualification. Strict type checking has zero errors. Twelve compiler
guards cover authority, arity, shadowing, initialization context and unsupported
payload operations. Two applied compiler controls remove construction/reference
authority and fail through the actual source-module factory in both targets.

The baseline compiler d0a6f01 rejects the same source's DataEvent type operation.
Adjacent error-event reference (23), construction (21), and ancestor static Boolean
(26) observations pass in both targets and realms, with their guards/controls.

Build using npm run tsc, then node tests/native-generated-data-event/run.cjs.
Set LAYA_ENGINE_REPOSITORY to the pinned engine if necessary. baseline.cjs reruns
the prior compiler rejection. retain.cjs accepts four completed reports in order:
DataEvent, error references, error construction, ancestor Booleans.
verify.cjs --check-current authenticates the retained comparisons and current inputs.

The feature requires explicit nativeDataEventReferenceModule and, for allocation,
nativeDataEventConstructionModule selection. Typed method returns use the exact
canonical reference. Native subclassing, constructor-parameter qualification,
class-initializer operations and payload writes remain outside this proof.
Full OP2 consumer integration, AlertChooseItem runtime and H5/account acceptance
remain pending. No font rendering changes are included.
