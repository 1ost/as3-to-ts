unchanged to the shared Vector provider, preserving evaluation order and the

existing allocation cap and independent ApplicationDomains. Three compiler

two-argument limit. A runtime regression control removes the new length check;
the resulting coercion of a string length disagrees with AIR on each target.

superseded by this runtime-checked constructor path. Unsupported specializations,
reflection and other operations keep their existing guards. The engine's
1,048,576-element allocation limit remains; this is not an unrestricted Vector
or whole-client acceptance claim. Reports, bundles and exact input hashes are
