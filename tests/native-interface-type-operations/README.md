Run `node tests/native-interface-type-operations/run.cjs --combined`, then repeat
with `--consumer`. Both modes authenticate the engine's interface-type-operations
packet and emit all nine complete subjects. Consumer mode excludes only Consumer
from class registration, retaining authenticated runtime/interface declarations.

strict generated/provider type errors. The source checks diamond inheritance,
lookalike rejection, primitive/nullish operands, single evaluation, throws and
initialization. Cast member calls evaluate arguments before null resolution;
getter/setter access uses the shared property helpers. Setter storage coercion
does not change the assignment expression's RHS value.

initializers, computed properties, updates and compound assignment boundaries.
Three comparison controls reject missing, reordered or changed observations.
