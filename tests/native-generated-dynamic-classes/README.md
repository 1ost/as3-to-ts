# Generated dynamic classes

Run `npm run tsc` and `node tests/native-generated-dynamic-classes/run.cjs`.
Five complete authenticated AIR source subjects produce 21 matching observations
on ES5/ES2015 in Node/Chromium, with strict checking of the real provider graph.
The compiler routes indexed source receivers and dynamic dot properties through
common property helpers. Explicit this access carries the compiler-held lexical
scope, preserving private/protected slots versus public dynamic namesakes.
Sealed children retain their own sealed status. Eight guards keep missing
providers, calls, updates, bare unresolved names and computed receivers held.

This does not qualify full dynamic lookup syntax or source object cloning. The
separate complete clone fixture uses its original class bodies and no script
globals (those subjects perform no lexical Function calls); serialization has
its own AIR evidence and must be verified separately.
