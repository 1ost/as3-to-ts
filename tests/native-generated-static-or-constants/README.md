Run `node tests/native-generated-static-or-constants/run.cjs` with the sibling
LayaAir-op2 checkout. The complete authored class matches four array-valued AIR
rows on ES5/ES2015 in Node and Chromium with zero type diagnostics. Own public
uint literal leaves and named OR chains support forward references and unsigned
results. A mutable uint field initialized from a combined constant is published
early; mutation during an earlier initializer is preserved. Eight guards reject
mutable, cross-class, cyclic, other-operator, grouped, signed, literal-operand and
out-of-range forms. Three controls reject altered comparison rows.

This does not qualify the complete Logger or arbitrary constant expressions.
