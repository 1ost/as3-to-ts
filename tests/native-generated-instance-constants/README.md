# Generated public instance literal constants

Run `npm run tsc` then `node tests/native-generated-instance-constants/run.cjs`.
The five complete captured AIR source classes are authenticated and emitted with
an explicit declaration plan. A separate host observer compares ten AIR rows in
Node and Chromium for ES5 and ES2015 output. Strict checking covers the real
provider graph with zero diagnostics; six rejection controls retain unsupported
computed, missing, reference, private, leading-zero and escaped-string cases.

The compiler projects inherited public primitive literal values into the common
registrar. Constructor entry installs readonly, non-enumerable own slots before
any source initializer, including before base calls. The full-source clone fixture
now emits Base and remains held on Record's dynamic property routing. This does
not qualify computed/constructor-assigned/reference/nonpublic constants, dynamic
classes, cloning or application completion.
