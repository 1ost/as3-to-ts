# Compiler declaration domain prerequisite

This opt-in compiler API allocates one common declaration token per complete source Class in a build domain. Class generation publication and existing self-reference coercion use that exact token. It does not lower foreign typed locals, derived classes, foreign method signatures, CLI configuration, or the maintained timing group.

The baseline is compiler `293d1b9ac9f602e67de240116b91a2e8f531e570`. The new complete five-class source fixture has 16 observations captured twice in Flash with complete Class and instance XML. Node and Chromium replay both ES5 and ES2015 emitted consumers against actual engine `7ae41d50d43f3288b17873922a903d3f0350a911` declarations. Engine code runs at its supported modern target. An optional engine `4c3eaf32cefc654e8b086036705c5576b9b4edf4` replay also matches these 16 rows and 17 controls. Its two externally observed error name/id rows do not exercise the separate source Error property API addendum; no Error compiler/property admission is claimed. Both engine identities remain explicit.

Caller workflow is demonstrated by `emit-domain.cjs`, using the exported `createNativeDeclarationDomain` API and ordinary `lib/parse` and `lib/emit` calls:

1. Authenticate the complete source and metadata tables, then call `createNativeDeclarationDomain({module, sources, metadata, lexicalModule, typedLocals})` once.
2. Emit `plan.moduleSource` to one compiler-owned resolved module. Every complete class must resolve `plan.module` to that same module. The sample caller's output-ownership map rejects a second domain writing that resolved output.
3. Emit every complete class using the exact `plan.metadata` capability and `plan.sources`. Ordinary outer options or an equal source-table copy may be used. Metadata copies, serialized options, and a marker without its private compiler association reject explicitly. To rebuild after serialization, supply the original authenticated inputs to the builder again.
4. Distinct domains require distinct resolved output modules, even if the relative module specifier is the same in different directories. The compiler cannot infer filesystem or bundler resolution from a module specifier. The caller must reserve the domain output against source and helper outputs. The builder rejects equality with its common metadata or lexical provider specifier; other aliases and resolved path collisions are caller-owned constraints.

The WeakMap stores compiler configuration capability, never a runtime source QName lookup. Generated token allocation imports only the common declaration provider. It does not import or read any lazy source Class. Publication exports are compiler machinery, not authored source bindings or new engine authority. The host remains a trusted compiler-provider caller; a digest field alone is not external authentication.

The retained 17 runtime controls cover token identity, private branding, copies, two independent same-name domains, unloaded-token coercion, reverse module load order, and module cache reuse. A separately labeled injected failure after the generated factory returns proves retry publication uses a fresh Class generation with the same token; it is not a claim that the held foreign-local initialization fixture emitted.

The 37 compiler/caller controls include immutable snapshots, mutation, copied/serialized contexts, repeat emission, retry after rejection, output ownership, cyclic/accessor configuration rejection, and builtin-name imports. Synthetic imported `Array`, `Number`, and `String` annotation controls remain explicitly held; they are rejection probes, not newly authenticated Flash fixtures. Intrinsic/import precedence is not generalized from short names.

`held-capture` retains the entire earlier original source packet, including 33 nominal observations, seven initialization observations, 14 Error observations, and complete reflection. Seven complete classes remain guarded. None of their foreign-local methods is replaced with a manually fabricated runtime replay.

Run from the compiler root after building with the existing TypeScript compiler:

```text
node node_modules/typescript/lib/tsc.js -p tsconfig.json
node tests/native-declaration-domain/guards.cjs
node tests/native-declaration-domain/holds.cjs
node tests/native-declaration-domain/run.cjs
```

Set `PYTHON` to the physical Python executable, `LAYA_ENGINE_REPOSITORY` to a repository containing the exact engine commit and installed dependencies, and `PLAYWRIGHT_MODULE` to the installed Playwright module. Optional `DOMAIN_ENGINE_COMMIT=4c3eaf32cefc654e8b086036705c5576b9b4edf4` runs the historical baseline. Test outputs live under `.cache/native-declaration-domain`; retained originals are never regenerated by these commands.
