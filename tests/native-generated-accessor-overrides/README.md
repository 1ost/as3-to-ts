# Generated public Boolean accessor overrides

Run `node tests/native-generated-accessor-overrides/run.cjs` after building the
compiler. Uses all five unchanged classes and the thirteen verified AIR rows in
`../LayaAir-op2/tests/nativeFlashOracle/generated-accessor-overrides`.

Production factories select an already loaded Base from a parent domain. ES5
and ES2015 run in Node and Chromium (CSP forbids evaluation), with strict provider
and generated-source type checks. The comparison covers partial/full overrides,
complementary halves through a grandchild, virtual base dispatch, direct-super
reads/writes, Boolean coercion, bound methods, ancestry, and getter-owned
reflection. Five runtime checks cover parent reuse, forged receivers, sibling
domains and retirement. Nine compiler guards and seven factory mutations reject
missing/wrong half authority, incompatible types, missing override flags,
signature getters and selected final parent halves.

Both getter and setter ownership are retained independently from reflection.
The runtime composes only authenticated selected-parent halves. Native accessors,
non-Boolean overrides, namespace accessors, super updates/compound assignment,
constructor/static/nested-function super access, and full application integration
remain outside this qualification. This is a member metadata projection, not
complete Flash reflection XML authority.
