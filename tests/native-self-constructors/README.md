# Authenticated optional self-reference constructor parameters

Build the compiler, then run `node tests/native-self-constructors/run.cjs`.
Set `PYTHON` to Python3 and `PLAYWRIGHT_MODULE` to an installed Playwright module
when needed. `LAYA_ENGINE_REPOSITORY` selects a repository containing engine commit
69789c4fa64dec426cf86a0ecd4cccfedf79be6c and its esbuild/TypeScript dependencies.
The runner archives immutable provider source and does not use working edits.

The unchanged maintained com.greensock.core.PropTween is emitted with metadata
authenticated from fresh original Flash reflection. All eight original PropTween
constructor cases match Node/Chromium for ES5/ES2015 generated syntax. Actual
TypeScript4.9.5 declarations pass with strict=true, strictNullChecks=false and an
ES2021 graph target. No declaration/source adaptation or Class substitutes exist.

The complete original capture retains32 constructor rows, identical to the
earlier prerequisite capture, plus exact Class/instance XML for six source
classes. The runner authenticates source/SWF/harness/commands/results, rebuilds
ordered metadata from XML using extract-metadata.py, and checks capture/source
hashes before emission. The original XML/source identities bind the metadata;
sorted member validation alone is not its authentication.

Supported constructors require nativeCallableMetadata and an optional own-class
reference parameter with a null default. The declaration token already exists
outside the lazy factory and acquires genuine instances through generation entry.
Coercion uses common as3CoerceReference with this token, without initializing a
Class through a type lookup. Own-class field types are resolved to the same
authenticated declaration and emitted as token-bearing property descriptors.

The maintained constructor is six-required/eight-total. Tests cover valid links,
omitted/null/undefined references, wrong objects/source Class values, String
coercion order and wrong-arity checks before hooks. Thirteen native boundary
checks reject forged prototypes/tags, preserve typed field assignment behavior,
and exercise common construction with the real declared class. Nine compiler
guards retain missing metadata, invalid defaults, changed source/reflection and
derived metadata limits. Four comparison negatives validate the comparison gate.

Twenty-four original rows are unselected here:14 String rows run separately in
native-string-constructors;10 instrumented SelfNode/SelfChild rows remain outside
this package. Derived source metadata still fails its existing ancestry guard.
Original subclass acceptance is retained as evidence and is not claimed ported.
PropTween itself is final, as authenticated from source and reflection. Full
GreenSock cycle/module/game completion remains separate.

Node vm is a test JavaScript realm only; production emits native JavaScript.
The driver supplies the same inputs and hooks. Its error marker is instrumentation,
not an AS3 Error constructor implementation. Reports include runtime bundles,
provider/compiler hashes, selected original rows, explicit unselected rows and
actual declaration results.
# Qualified source identities

The suite also retains 30 original comparisons covering qualified own-class types,
same-file declaration/import precedence, builtin String/import precedence, and null
defaults for qualified static/instance fields whose classes are named Number or Boolean.
Together with the eight maintained PropTween cases, all 38 run in Node and Chromium
for ES5 and ES2015 output against actual common provider declarations. Qualified
source names survive parsing and AST filtering; coercion uses the private declaration
token rather than the terminal identifier's builtin spelling. Ambiguous unqualified
own/builtin types remain rejected. No general foreign reference binding is admitted.
