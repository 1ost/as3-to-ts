# Generated retrying source ancestry

Build with `npm run build`, then run
`node tests/native-generated-retry-ancestry/run.cjs`.
The engine defaults to `../LayaAir-op2-retry-ancestry-review`; override with
`LAYA_ENGINE_REPOSITORY` for another reviewed provider revision.

Both ES5 and ES2015 match eleven retained AIR observations in Node and Chromium
under strict script policy, with eight runtime/domain checks and zero explicit-
root type errors. Six compiler guards cover absent retry selection, forged plans,
native-root ancestry, cycles, internal storage and a reverted planner boundary.
The mutation restores the non-retrying-only ancestor loop and must reject the
exact positive cohort. Generated modules, source and type/bundle hashes are kept.

A failed root prevents leaf initialization; a successful root remains published
when the leaf later fails. Retried leaf identity is fresh, but leaked instances
retain source declaration type identity. The fixture observes inherited lexical
storage, constructor order, super method dispatch and deferred String constants.

Source-only ancestry may now include retry-selected parents. Sprite ancestry
keeps its non-retrying-parent boundary; other native bases and package-internal
derived retry storage remain held. Existing tests that treated retrying source
roots as invalid now reject unresolved ancestry instead; newly valid selections
have positive plan assertions. The Sprite regression runners accept an optional
`OP2_PROVIDER_LOCK` for their source probe and use the selected engine consistently
for nominal runtime types, avoiding mixed-checkout declaration brands.

This is lifecycle qualification, not complete OP2 factory/runtime acceptance.
