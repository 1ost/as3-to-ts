# Implicit native base constructors

Run `npm run tsc`, then `node tests/native-generated-implicit-native/run.cjs`.
Six complete AIR subjects are emitted by the production class module factory.
Both ES5 and ES2015 match all 19 original observations in Chromium running real
Laya, with no type diagnostics or browser errors. `verify.cjs` checks the retained
receipt against the original source, runner, observer and compiler change.

The shared compiler admits implicit zero-argument base construction only for the
qualified Sprite and EventDispatcher protocols. Omitted constructors keep their
own zero-argument signature; source fields retain Flash ordering. Explicit bodies
without an authored super call retain parameter defaults/coercion, native base
initialization and their original body effects.

Six compiler guards retain plan authenticity, native-base providers, exactly one
unconditional explicit super when present, and the hold for unqualified native
bases. Two applied bundle mutations duplicate the synthesized native base entry
for EmptyDispatcher and EmptySprite; the real native adapters reject both.
Removing the default dispatcher base entry is not an observable negative control
for this fixture because native preparation supplies the same default state.
Full OP2 startup and real-account validation remain separate work.
