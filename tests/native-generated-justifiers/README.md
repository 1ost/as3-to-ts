# Generated justifier references

The production factory emits the complete original JustifierParent and
JustifierChild classes for ES5 and ES2015. Each target passes 128 original AIR
observations in Node and CSP Chromium: 101 engine Class/property observations
plus 27 generated field, override/super, construction, clone, locale-factory
and nominal `is`/`as` observations. All three generated source outputs typecheck
without diagnostics. Twelve negative configurations reject incompatible
signatures, absent qualification and mismatched module/import/export bindings.
Two applied controls reinstate the old native-signature and native-super gaps.

    npm run build
    node tests/native-generated-justifiers/run.cjs
    node tests/native-generated-justifiers/verify.cjs --check-current

The default engine is the sibling LayaAir-op2-justifier-review; override with
`LAYA_ENGINE_REPOSITORY`. Original evidence is retained there under
`tests/nativeFlashOracle/generated-justifiers` and `text-justifier-references`.
The report authenticates compiler, bundled and typechecked inputs, source
captures, observer, runner, emitted artifacts and both runtime results.

`nativeTextJustifierReferenceModule` requires exact, authenticated justifier
providers and matching imports. It admits typed returns and method-local
nominal `is`/`as` operations using shared source helpers. It grants no generated
native subclass entry, TextBlock binding, font layout or game-startup completion.
Run with `--emit-only` only for emission/typecheck inspection; that mode records
no runtime qualification report.
