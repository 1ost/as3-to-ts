# Generated Object/wildcard indexed mutations

Run run.cjs after npm run tsc. Both complete AIR Mutator/Slot subjects emit with
the reference-coercion pass and compare all 19 captured rows in Node and Chromium
on ES5/ES2015. Strict generated and common-provider types must have zero errors.

The explicit nativeDynamicPropertyWritesModule now lowers indexed += and delete
on source-bound Object/wildcard identifier receivers. The common addition helper
captures the read receiver and raw key value; it runs the read before the RHS,
rereads the receiver for storage and returns the uncoerced assignment value.
The AIR packet proves receiver reassignment, key reassignment and conversion
ordering, accessor effects, Array holes and branded source failures.

Ten guards retain invalid/missing providers, calls, increment and other compound
operators as holds. Computed receiver expressions and broader mutation families
are not qualified. The host observer is separate from the unchanged subjects.
