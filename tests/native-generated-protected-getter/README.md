# Complete protected Boolean getter Classes

Build with `node node_modules/typescript/bin/tsc --pretty false`, then run
`node tests/native-generated-protected-getter/run.cjs`. The engine path can be
selected with `LAYA_ENGINE_REPOSITORY`; evidence is read from immutable engine
commit `5ff09c009` and authenticated against its original AIR receipt.

All three complete original subjects are compiled as native source Class
factories for ES5 and ES2015. Nineteen observations from two identical AIR
captures match in Node and Chromium with a self-only script CSP and zero type
errors. No native protocol subject bodies replace compiled source bodies.
The retained report is verified by `verify-runtime.cjs --check-current`.

The admitted source shape is an instance protected read-only Boolean getter.
Explicit overrides require a nonfinal source ancestor. Reads use the shared
lexical capability; `super` in an instance method or getter selects the source
ancestor on the original receiver. Source return coercion remains in each body.
Protected getters stay absent from public property access and reflection.

Sixteen rejection guards cover forged plans, invalid overrides, final ancestors,
private/static/non-Boolean getters, parameters, root super, writes, updates,
calls, deletion and setter halves. Two applied factory mutations independently
turn super into recursive virtual dispatch and remove the child's negation;
both are detected in both runtimes. Report: `full-cWqIk8`.

Adjacent complete-source regressions pass on both targets: protected super
methods (16 AIR rows, `run-QFkk4O`), protected numeric super fields (12 rows,
`run-xfqKmL`), internal getters (13 rows, 22 guards, `run-NxAvr3`) and mixed
accessor halves (17 rows, 12 guards, `full-BMPMd2`). The internal-getter suite's
former protected-Boolean exclusion now checks protected uint instead.

This fixture qualifies source compilation and dispatch, not full OP2 startup
or supplied-account game flows. Other protected accessor shapes remain held.
