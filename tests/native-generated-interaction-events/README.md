# Generated maintained interaction interface

The complete maintained IInteractionEventHandler source and a fixture
implementation of all twenty methods are emitted as class factories in ES5 and
ES2015 and loaded into separate ApplicationDomains. The shared canonical event
reference provider supplies Event, MouseEvent, KeyboardEvent, FocusEvent,
TextEvent, IMEEvent and ContextMenuEvent identities. No application interface
signatures are rewritten and no compiler admission rules are relaxed.

Both targets match 201 original AIR observations in real Laya Chromium with zero
type diagnostics or browser errors: interface is/as identity and twenty typed
methods receiving ten representative values each. Eight compile guards reject a
forged plan or each missing event provider. Twenty runtime guards reject missing
method arguments. Sibling domains keep separate interface identities; retiring a
session preserves existing instances. Original evidence and maintained source
provenance are retained in engine
tests/nativeFlashOracle/generated-interaction-event-references.

```powershell
node tests/native-generated-interaction-events/run.cjs
node tests/native-generated-interaction-events/verify.cjs
```

The retained compressed report includes complete emitted artifacts, source hashes,
compiler input hashes and consumed provider graphs. The verifier authenticates
fixture sources and compiler inputs against the retained run. Native source event
construction/member behavior, operating-system IME and whole application startup
remain separate qualifications. This test proves the existing generated interface
and method-reference path works with the newly authenticated event identities.
