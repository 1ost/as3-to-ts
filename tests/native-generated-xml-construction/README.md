# Generated source XML String construction

Run `npm run tsc` and `node tests/native-generated-xml-construction/run.cjs`. The production native Class module factory emits the complete, unchanged XMLBuilder captured by AIR. All 84 constructor and UTF-16 edge observations run on ES5/ES2015 in Node and Chromium under script-src self, with zero generated/provider type errors. Each target checks eight rejection guards, two domain/node isolation checks and an applied String-as removal mutation.

The compiler admits zero-argument construction or one source String binding, String literal, null, or authenticated intrinsic String-as expression. It requires exact XML global/declaration providers and emits common as3ConstructXMLString. Source XML returns preserve canonical reference coercion. Raw wildcard input, String/XML shadows, extra arguments, XMLList construction and missing/mismatched providers remain held. Global builtin providers must not be listed as source classes in definitionsByNamespace.

Mutable XML Class settings, arbitrary Object/ByteArray/XMLList constructor conversion and full ResourceLoader/game integration are not qualified by this fixture.
