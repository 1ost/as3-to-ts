# Generated source reference constructor parameters

Run npm run build and npm run test:native-reference-construction. The fixture
verifies the common engine's pinned reference-construction AIR packet, then emits
all five original source classes without body rewriting. Sixteen AIR observations
pass on ES5/ES2015 in Node and Chromium with strict provider-graph types. The
native TypeScript observer preserves argument lists and normalizes JSON capture
format, not source behavior. Five compile guards reject unqualified defaults,
unresolved types, native reference types and rest parameters.

Constructor annotations resolve by exact source owner/span in the immutable
generated declaration plan. Only a planned source declaration supplies the token;
source names or matching JavaScript shape cannot grant reference identity. The
existing common AS3Property coercion provider checks each supplied argument in
signature order, before generated field initialization and source body effects.
Optional source references accept only literal null defaults. Converted supplied
arguments update the source arguments array; omitted defaults do not add entries.

The packet covers derived/exact identity, null/undefined, invalid structural and
primitive values, failure before later scalar coercion, required arity and failed
base entry after child effects. The arguments-using constructor retains surplus
arguments according to AIR. Native reference parameter types, interfaces, vectors,
non-null defaults and general generated typed method returns remain separate.
This is not validation of every OP2 data class or real-game flow.

The fixture also enables ordinary numeric-method conversion alongside generated
constructor conversion, as bulk emission does. A separate NumericEntry regression
checks an optional int constructor without source arguments, its default and one
valueOf evaluation. Generated entry owns these constructor parameters; the numeric
method pass must not inject a second arguments-dependent conversion into its body.
This extra regression is not counted among the five unchanged AIR classes/16 rows.
