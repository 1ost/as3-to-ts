# Generated Vector accessors

Run `npm run tsc`, then `node tests/native-generated-vector-accessors/run.cjs`.
The complete unchanged captured Subject goes through the production factory on
ES5 and ES2015, strict generated/provider typechecks, Node and Chromium under CSP.
All 25 AIR rows cover getters, setters, exact specialization, null/undefined,
invalid values, conversion/body order and allocation identity. Separate domains
and an applied alteration of the fresh getter's element are checked. Source application
integration, accessor overrides and complete reflection remain separate work.
