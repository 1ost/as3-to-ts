# Generated String for-each

Run `node tests/native-generated-string-foreach/run.cjs` after `npm run tsc`.
The complete captured source subject is emitted against the generated declaration
domain and compared with fourteen authenticated AIR observations on ES5/ES2015
in Node and Chromium. Both generated and dependency type diagnostics must be zero.

Qualified existing String locals use the common enumeration cursor and String
assignment coercion. Null/undefined retain the source null String value; simple
typed-local typeof reads preserve the source string result. The fixture covers
sparse/scalar inputs, Dictionary values, stable receiver evaluation, break and
continue, conversion hooks and failed conversion preserving previous storage.
Six rejection guards retain required providers and reject unqualified target
forms; three comparison controls reject missing, reordered or changed rows.

Other primitive, inline, parameter, member and catch-shadow targets remain held.
This prerequisite does not qualify the complete JsonConfigProxy application.
