# Stable multilevel Sprite ancestry during Class retries

Run `npm run build`, then
`node tests/native-generated-multilevel-sprite-retry/run.cjs` with the pinned OP2
and engine sibling checkouts. Five complete, unchanged source classes are loaded
through generated source-class factories. The shared engine evidence verifier
authenticates eighteen repeated browser Flash/AIR rows before comparison.

Both ES5 and ES2015 pass in Chromium with real Laya/Sprite initialization, strict
browser CSP, zero TypeScript errors, ten rejection guards, eleven domain checks
and one detected mutation. The rows include escaped failed-Class construction,
stable two-level ancestor/interface membership, inherited fields and methods,
fresh retry globals/closures/arrays, and successful initialization only once.

Every source ancestor must have its planned script global and remain outside
`classScriptSources`; the chain must reach authenticated native Sprite. The
previous immediate source-root and direct EventDispatcher cases remain accepted.
Direct Sprite leaves, retrying intermediate/root ancestors, cycles, missing
native entry authority, and deeper source-only roots remain rejected. The emitter
still requires separate authority for ancestor static initializers.

The fixture passes its own Class directly from the initializer to a static
method. This matters: the retained method-reference variant compiles differently
in Flex and AIR. The browser evidence does not qualify arbitrary static-method
self references. OP2's original WindowLayer initializer independently uses the
same direct current-Class operand. Full WindowLayer and startup remain open.
