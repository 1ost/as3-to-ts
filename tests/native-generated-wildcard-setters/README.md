# Generated wildcard-return setters

Allow the maintained AS3 wildcard setter result type and qualify public wildcard
accessor halves, including direct super calls. The callable emitter already turns
accessors into ordinary functions installed through descriptors; setter result
values remain intact inside the body and property assignments discard them.

The five complete original AIR Classes pass 24 observations on ES5 and ES2015
in Node/CSP Chromium with zero strict type diagnostics. Twelve compiler guards
cover exact-plan identity, override/final ownership, mismatched inherited halves,
duplicate getters and unqualified setter results. Two applied factory controls
reject corrupted override authority in both runtimes.

Run run.cjs with LAYA_ENGINE_REPOSITORY set to the shared engine checkout.
verify.cjs --check-current authenticates the retained sources, generated artifacts
and runtime observations. engineCommit in the report is the checkout base at
capture; source input hashes identify the tested patch. The original compiler
rejects these subjects at the setter-signature guard. The adjacent 23-row String
accessor and 41-row independent accessor-type fixtures pass on this patch.

This is shared language/runtime qualification, not OP2 text-layout or startup
completion. Maintained sources are unchanged.
