# Generated TextLine constructor references

An explicit `nativeTextLineReferenceModule` admits TextLine constructor
parameters through the authenticated declaration/reference plan and matching
provider/import binding. The emitted boundary uses the common reference
coercion helper. Optional literal-null defaults, argument-count checks and
coercion-before-body ordering retain their existing behavior.

The complete OptionalLine and RequiredLine AS3 classes are compiled unchanged
and loaded through a real native source-class loading session. All 31 original
AIR observations match in ES5 and ES2015 under initialized Laya in CSP Chromium,
with zero type diagnostics or browser errors. Seven compiler guards reject
missing/mismatched authority, invalid modules, copied plans and non-null defaults.
Six runtime guards reject forged/proxied/copied lines before constructor effects.

`tests/nativeFlashOracle/generated-text-line-constructors`. The retained report
contains compiler/provider hashes and emitted source. This is constructor
reference admission; TextLine member dispatch, reflection, native construction,
font-backed layout, full TLF and OP2 startup remain separate requirements.
