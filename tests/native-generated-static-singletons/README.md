# Generated nonpublic static storage

Run npm run tsc, then node tests/native-generated-static-singletons/run.cjs.
Repeat with --combined for overlapping scalar/reference signature passes.
The runner authenticates generated-static-singletons AIR evidence and emits all
five complete subjects unchanged. Its separate observer compares all 32 rows in
Node and Chromium on ES5 and ES2015 with zero generated/provider type diagnostics.

Own private/protected static variables use common AS3LexicalMembers storage,
including constructor references to bare static names, typed writes, raw
assignment results, defaults and independent class slots. Static initialization
publishes observed int literals and null storage before computed reference
initializers execute in source order. Retry tests require fresh Arrays after each
failure, original thrown-sentinel identity, and stable storage after success.
No source class or application implementation is replaced by the observer.

Nine rejection guards retain nonpublic static constants, other primitive
initializers, parenthesized Object literals, Vector statics, protected static
methods, static Function-slot invocation and inherited protected static ownership
as separate prerequisites. Three comparison controls detect missing rows, changed
order and loss of the raw undefined assignment result. Script-global publication
with static initializer retries also retains its existing independent hold.

Only signed decimal int literals within int range and null are early static
values in this change. Computed reference initializer grammar remains bounded
to Arrays, calls, construction and references. Wider primitive constants,
inheritance, initialization cycles, protected constants and full EMVC operation
require further evidence and implementation. This fixture alone does not prove
bulk-worker or application admission.
