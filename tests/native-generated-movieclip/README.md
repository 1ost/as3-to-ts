# Generated MovieClip subclasses

Build the compiler with `npm run build`, then run `node
tests/native-generated-movieclip/run.cjs` and `node
tests/native-generated-movieclip/execute.cjs`. Set `PYTHON` to a Python 3
interpreter and optionally `LAYA_ENGINE_REPOSITORY` (default `../LayaAir-op2`).

The planner accepts the explicit MovieClip native-base provider and imports its
source-surface check, declaration token and native allocation entry. Trait
projection includes all 105 inherited members, their declaring classes, types,
access facets and method parameter counts. Fifteen nominal reference types need
explicit bindings. Source subclass dynamic flags remain declaration-specific.
Reference-only bindings grant no native-base authority. Native overrides and
MovieClip Class-script retries remain separate prerequisites.

`verify.py` independently parses the original XML after checking pinned receipt,
artifact/source hashes, identical captures and complete observation arrays.
`generate.cjs` reproduces the trait table; use `--check` for verification.
The projection test checks both inheritance levels and 25 controls, including
unrelated EventDispatcher overrides in a mixed cohort. Its placeholder module
paths are never executed.

The execution test emits complete ES5 and ES2015 modules from the unchanged
captured `SurfaceChild` and `ConstructionLog` source. Real Laya runs in Chromium
under script CSP. Both full constructor observations match Flash: native state
exists during field initialization, and pre-super writes survive super entry.
Five guards cover native brands, exact prototype, independent native state,
stable inherited method closures and readonly property errors. Two mutations
per target must be caught: losing a pre-super write and skipping native prepare.
Generated classes and their provider graph have zero TypeScript errors. Reports
retain source bytes, artifacts, results and input hashes below
`.cache/native-generated-movieclip/`.

The default-package fixture needs private lexical members but no internal package
membership, so it does not request a package membership provider. It exercises
ordinary code-created subclasses, not authored symbol construction or full game
startup. Class-level `Embed` metadata now explicitly requires authenticated
authored construction; the retained UI_CheatPanel source is a rejection control.
It must never silently become an empty native MovieClip.

Regression checks retain Sprite's full projection, declaration planning, trait
storage and generated Event behavior. The older declaration emission test still
expects rejection of a private static constant; its failure reproduces with both
changed compiler modules loaded from the prior committed baseline.
