# Source String constructor parameters

Build the compiler, then run `node tests/native-string-constructors/run.cjs`.
`PLAYWRIGHT_MODULE` may identify an installed Playwright module. The sibling
LayaAir-op2 repository must contain engine commit69789c4fa64dec426cf86a0ecd4cccfedf79be6c
and its esbuild/TypeScript dependencies; `LAYA_ENGINE_REPOSITORY` can select it.
The runner archives that immutable commit, ignoring working provider changes.

The emitted original StringPair, OptionalString and Journal classes match14
authenticated Flash observations in Node and Chromium for ES5 and ES2015 output.
Cases cover required/optional parameters, a String default and null default,
supplied null/undefined/scalars, custom String conversion hooks and errors,
formal conversion ordering, argument evaluation, the constructor body and
supplied arguments updates. The common as3CoerceString provider owns conversion.
Configure `nativeCallableStringModule` with the common AS3String module path.
It is separate from `nativeCallableCoercionModule`, which remains the numeric
AS3Coercion path; AS3Coercion does not itself export as3CoerceString. This fixture
checks a distinct AS3String import using the actual provider declaration and
reexports the same bundled provider function in its test module loader.

The typed graph uses unmodified declarations generated from the actual pinned
provider source with TypeScript4.9.5, strict=true and strictNullChecks=false.
Graph validation targets ES2021; generated class syntax is separately tested
at ES5 and ES2015. Runtime dependencies require modern JavaScript. No historical
ES5 browser support is claimed. Node vm creates a test-only JavaScript realm;
production emits native JavaScript and does not execute SWF bytecode.

The full original capture has32 rows. Eighteen self-reference/actual PropTween
rows remain retained and unadmitted. Self-references and other unproved parameter
types stay explicit compiler errors. Actual maintained PropTween now stops at
its PropTween-typed seventh parameter, so this suite does not admit the timing
cycle. Only String/null literal defaults are admitted; undefined, numeric,
Boolean and identifier defaults remain explicit guards.

Source constructors with an arguments read can accept extra dynamic arguments;
static AS3 calls still have compile-time arity restrictions. This patch preserves
the established usesArguments behavior, as well as omission versus explicit
undefined. No new static-call validation is claimed.

Evidence integrity: the runner pins the original provenance receipt and verifies
all retained AS3, SWF, capture harness, command and Flash result hashes. The source
copies are verbatim. All32 observations and the exact maintained PropTween source
remain in evidence; the runner selects14 by named String/optional case families.
The driver supplies the same inputs/events without changing expected results.
Its thrown hook sentinel carries the original name/errorID as instrumentation;
it does not claim to test construction of AS3 Error. Original tool binaries and
browser profiles are not packaged.

Four comparison negatives and12 compiler guards are checked. Both generated
targets are tested against real provider declarations without source/declaration
rewriting. Reports retain provider/compiler hashes and runtime bundles under
`.cache/native-string-constructors/run-*`.
