with zero type/browser errors. Cases cover optional/required Matrix parameters,

counts, identity and pre-body errors. The maintained constructor also verifies
mixed numeric/string/display parameters and DisplayObjectContainer nulls,

Matrix/container options and null-only defaults. Three runtime guards reject
forged Matrix and container values. The shared engine publishes Matrix's closed

complete TLF layout. Source provenance is retained in the original engine packet.
