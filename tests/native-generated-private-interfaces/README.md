# File-private interface headers

Run after `npm run build`:

```
node tests/native-source-unit/interfaces.cjs
node tests/native-generated-private-interfaces/run.cjs
```

The engine's authenticated `file-local-interfaces` packet supplies four complete
AS3 files and 21 repeated Flash observations. Planning preserves separate opaque
identities for three private interfaces, public and private interface ancestry,
and their original source files/import scopes. Five declared contract members
produce 22 Class implementation checks including inherited surfaces.

Private interfaces occupy `plan.privateInterfaces`; `plan.interfaces` remains
the public table. Private tokens use the common nominal interface provider,
never Class publishers or public definition names. Nineteen header checks run
on ES5/ES2015 in Node and CSP Chromium with zero generated/provider type errors.
Thirteen guards cover authority, unsupported module publication, cyclic or
missing bases, Class/interface confusion, signature mismatch and duplicates.

This does not replay source method bodies. Class emission for a source file
with private interfaces and complete cohort module publication remain explicit
holds. Next connect the internal interface view to typed/callable/trait lowering,
emit selected original interface ASTs, and preserve private token identity when
public source Classes are inherited from an existing domain. Then replay the
complete Flash packet plus native sibling/inherited-domain lifetime cases.
Public interfaces extending private interfaces remain outside admission.
