# Authenticated frame-script pair subset

The authored source diagnostic retains the original totalFrames-1 and totalFrames-10 arithmetic, closures, null removal and multiple pairs. This is not a replacement application class. Native evidence comes from the separately source/SWF-bound authored 28-frame fixture in Laya. Generated execution compares callback IDs and frame order against that evidence; receiver identity, parent removal and real authored content rendering remain covered separately by the Laya native fixture/runtime suite.

The profile preserves actual SDK variadic authority (0..1000000 arguments, wildcard rest). The shared adapter narrows admitted calls to nonempty even numeric-frame/Function-or-null pairs. Unknown and invalid arguments stay held; the shared bridge retains runtime range/integer behavior.

Run the opt-in frame-script-pairs.test.cjs with FROZEN_LAYA_ROOT or HARDENED_FIXTURE_LAYA and HARDENED_FIXTURE_AIR_SDK/HARDENED_FIXTURE_FFDEC after building the candidate compiler. Failed artifacts are retained. The runner uses the actual MovieClip with a fixed 28-frame native timeline driver, not a replacement MovieClip implementation.
