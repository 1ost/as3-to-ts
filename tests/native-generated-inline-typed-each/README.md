# Generated inline typed for-each declarations

Run `npm run -s build` then `node tests/native-generated-inline-typed-each/run.cjs`.
The runner authenticates and emits both complete shared Flash source files with
the actual native source-class module factory. Generated TypeScript and its real
provider dependencies must typecheck without diagnostics. ES5 and ES2015 run in
Node and Chromium with an external-script CSP and match all nine Flash rows.

Function storage supplies reference/numeric defaults before the first iteration.
The common enumeration cursor captures the receiver once and closes on abrupt
completion. Each assigned value passes the existing typed-local coercion before
it replaces prior storage. Empty/null receivers leave defaults intact. Failed
reference coercion retains the previous iterator value. Vector iteration,
integer conversion and break/continue are compared against the captured runtime.
Three guards reject absent enumeration providers, conflicting iterator storage
and unresolved element classes. Generated sources, provider hashes, type checks,
results and observer/runner hashes are retained under `.cache`.

This also clears First's inline iterator in the unchanged private-helper lexical
fixture. Complete private source-unit callable emission and initialization are
separate prerequisites; this test does not claim them or OP2 startup complete.
