# Generated canonical content-family Vectors

Run `node tests/native-content-vectors/run.cjs --combined` from the compiler root
after `npm run tsc`. LAYA_ENGINE_REPOSITORY optionally selects the common engine;
the default is ../LayaAir-op2. `verify.cjs` authenticates the retained proof.

Four complete AIR Consumer sources generate for ES5 and ES2015. Both execute
against real native content classes in Chromium with Laya and match all 164
original observations. Forty compiler guards cover each family's exact provider,
Vector admission, shadowing/nested-vector restrictions and reference option
bindings. Sixteen native guards reject forged constructor/prototype identities
and proxies without consulting traps. Three comparison controls reject altered,
missing and reordered reference rows. Generated code and dependencies have zero
TypeScript diagnostics. The adjacent TabStop Vector suite also passes at these
compiler inputs.

The explicit nativeContentElementReferenceModule option authenticates all
selected family providers and permits typed native returns. nativeVector admits
the four exact FTE names, not arbitrary native classes. The common reference
module reexports the existing private allocation declarations; no second type
identity or host-array representation is introduced. Base content vectors accept
native subclasses while preserving each vector specialization's identity.

The observer supplies native content instances to the generated consumer. This
qualifies collection/reference behavior, not generated native constructors,
property dispatch, reflection, TextLine composition or application startup.
