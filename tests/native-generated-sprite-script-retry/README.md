# Retryable Class scripts over Sprite ancestry

Run `node tests/native-generated-sprite-script-retry/run.cjs` from this checkout,
with the isolated OP2 and engine sibling worktrees. It verifies retained AIR
evidence in OP2's `game-client-laya/tests/sprite-script-retry`, then emits the four
complete sources through the production factory on ES5 and ES2015.

Real Chromium/WebGL under script-src 'self' compares sixteen original observations,
nine independent/inherited domain checks, six rejection guards and an applied
mutation removing Class-script identity authority. All generated sources and
their actual native dependencies receive TypeScript checking. Reports retain
compiler, generated and type-input hashes.

The new admission is a retrying source leaf above a stable source parent whose
base is the authenticated native Sprite provider. Direct native leaf retries,
retrying parent initializers and other multilevel native ancestry remain held.
This is prerequisite coverage for Game's executable static initializer; it does
not establish full Game dependency closure or startup.
