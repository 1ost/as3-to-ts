# Native generated optional/rest callables

Run `npm run test:native-generated-optional-rest` after building the compiler.
The engine checkout defaults to `../LayaAir-op2` and may be overridden with
`LAYA_ENGINE_REPOSITORY`. Its authenticated `generated-optional-rest` AIR packet
must be present. No source subject is rewritten or omitted: all eight complete
classes and the interface are emitted, while the separate observer drives them.

All 56 repeated ADL observations must match in Node and Chromium for ES5 and
ES2015, both with and without numeric/reference signature passes enabled.
The suite checks real-provider TypeScript diagnostics, 19 admission guards and
five altered-comparison controls. Generated and provider source hashes are
retained in each ignored report. Modern support helpers use the engine compiler;
the generated application files use the transpiler's TypeScript version.

Entry code selects optional defaults by argument count, so explicit undefined
still undergoes the declared coercion. Optional defaults are bounded literals.
Generated methods own parameter conversion instead of also running the ordinary
numeric parameter pass. Rest Arrays are sliced from supplied arguments, and rest
storage is subject to the common Array coercion on reassignment. Fixed parameters
are retained as actual JS formals; defaults/rest do not distort Function.length.
Public/lexical method traits exclude rest from their parameter count. Constructor
rest is prepared before field/body effects and supports source `super(rest)`.
Slot-shaped Function parameters use common property coercion. Generated builtin
Array tests use the common AS3Type provider instead of the legacy AS3Utils path.

Rest without typed storage, malformed required-after-optional signatures,
computed/invalid defaults, rest compound/update/redeclaration/catch writes,
method arguments and constructor rest plus arguments remain rejected. Rest
super-method dispatch remains held. No arbitrary anonymous/nested callable or
complete Signal runtime admission is implied. SlotList.NIL, source Error catch
identity for arity failures, full diagnostic text and reflection are not proved
by these rows. The observer catches wildcard thrown values and reads host/source
error fields according to their representation; it never equates their brands.
