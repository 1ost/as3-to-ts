# Generated Object/wildcard indexed reads

Run run.cjs. It authenticates and emits both complete AIR subject classes, then
compares all 15 rows on ES5/ES2015 in Node/Chromium against actual common providers.
The reference-coercion pass is required for the source Error catch. Reports retain
source, observer and provider hashes and strict generated/provider diagnostics.

The explicit nativeDynamicPropertyReadsModule option dispatches indexed reads of
source-bound Object/wildcard identifiers through as3GetProperty. It preserves key
expression order, null receiver errors, bound method identity and discarded reads.
Eight rejection guards retain invalid provider modules and direct calls, updates
or deletion as holds instead of stripping receiver/assignment semantics. Existing
qualified writes use the separate write provider. Computed receiver expressions
and broader dynamic operations remain separate work. This is not full ObjectUtil
or JSON/object-codec qualification.
